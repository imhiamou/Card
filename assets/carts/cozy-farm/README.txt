FREE COZY FARM TILESET SAMPLER

A free sample of the Cozy Farm Tileset: one full terrain pair (grass / path -
dirt paths) with every corner (Wang) combination, ready for Godot 4 and
Tiled. Free for personal and commercial projects.

WHAT'S IN THE BOX

tiles_128/ tiles_64/      base tiles (grass, path) + 16 corner transition tiles
atlas/                    one atlas PNG per size + atlas_layout.json
godot4/                   Godot 4 project: cozy_farm_tileset_64/128.tres + demo.tscn
tiled/                    cozy_farm_sampler_64/128.tsx (corner wangset)
sample_map.png            a map built only from these tiles

Corner tiles are named <lower>_<upper>_<NW><NE><SW><SE>_1.png, each digit is
one tile corner: 0 = grass, 1 = path.

THE FULL COZY FARM TILESET
285 tiles per size: 8 terrains, 8 transition sets, 2 shape variants
for every corner tile, 64 / 128 / 256 px, the same Godot 4 and Tiled setup.
https://antahonist.itch.io/cozy-farm-tileset-autotiles-for-godot-tiled
